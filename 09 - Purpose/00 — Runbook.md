# Runbook

Written 21 August 2026. This is the operating file for the whole life, not a plan for it. Open it on Sunday when you set the week, and on any morning where the question is what am I supposed to be doing.

Everything else in `09` is a plan from an earlier month. This file says what is actually running, what it is measured by, and what to drop first. Where the old files still hold, it says so. Where they are dead, it says that too.

Rule for this file: it records the state, it does not invent one. Anything marked **UNVERIFIED** is a plan of record that has not been checked against what you have really been doing. Fill those in yourself. Do not let them sit unresolved for a month.

## 1. The standing day

The day was rebuilt 10 and 11 August 2026 on one finding, which is yours: *usually not being in my room helps so much*. The variable is the room, not the activity. In-room work runs in daylight when it competes with nothing. Evening slots go to things that happen physically elsewhere.

The rail, in order, every day:

| When | Thing | Why it sits there |
|---|---|---|
| On waking, outside | Rosary in the sun, while hydrating | Stacked onto waking. Needs no text. Survives busy days. |
| Morning, 20-30 min, 5x/week | The block: psalm reconstruction from memory, then correct against the AELF text | This is one activity, not two. Reconstructing then correcting **is** the Pascal French drill with the psalm as answer key. Off-days must be **named the day before** or the skip becomes the default. |
| Dead time, free | Retrieval. Car, walk, between sets | No text available, so it forces recall instead of rereading. This is where the repetition load actually gets paid. |
| Daytime, 5x/week | Reading, before the writing block | Daylight, in-room, competing with nothing. |
| 14:00, daily, whole | Writing. Six log sentences minimum | **Never fragment this block.** |
| 17:00-18:00 | The walk. Vocal recall from memory, out loud | The load-bearing slot. It fills the pre-Ari window that was the original problem, and vocal recall is one of the very few things that **cannot** coexist with checking a phone. Reading can. Writing can. Watching can. |
| Before sleep | Compline, then the incipit index, first lines only, 2 min | Prayer, psalm maintenance and anti-bleed in one act. |

**The call-day version, decided now so it is never decided at the time.** Morning block drops. Rosary on waking stays. Compline stays. Pull one of the short reserve psalms: 116 is two verses, 130 is three. A low day is a setting on the system, not a failure of it.

## 2. The week

Four day types. The old `Schedule.md` had these built around the liturgical Hours and a Tim Mackie slot. The shape survives, the contents changed in August. This is the current version.

| Day | Type | Body | Production block |
|---|---|---|---|
| Mon | **A** Gym | Gym, 30 sets, intensity day. Treadmill 25 min at 12% **after** lifting. No burpees. | none |
| Tue | **B** Home | Burpees on the roof, morning | Video / method |
| Wed | **B** Home | Burpees, morning | none |
| Thu | **A** Gym | Gym, 30 sets, volume day. Treadmill after. No burpees. | none |
| Fri | **B** Home | Burpees, morning | Video / method |
| Sat | **B** or **C** | Burpees, morning | none |
| Sun | **D** Assembly | Burpees, morning | Video / method **plus** the weekly assembly, below |

**Type C is the travel or uni day.** Audio during the commute, survive the meetings, morning block if it fits, walk if it fits, Compline always. It replaces whichever type it lands on. It does not get made up later.

**Type D, Sunday, is the only day with real work that is not daily work.** Three things and nothing else:
1. **Pick the charge** for the coming week's log, before the week starts, so the material sorts itself and you are never choosing between good things.
2. **Assemble** the piece out of the six days behind you.
3. **Turn the dial**, once, on food. See section 7.

**Why the video block sits on Tue, Fri and Sun:** so that Monday and Thursday are not carrying the gym plus a production day. Keep that property if the week ever moves. The same logic put the two gym days on the two burpee rest days, so a 30-set day never also carries 400 push-ups.

## 5. Drop order

When the day is short, drop in this order and stop when it fits. Deciding this now is the entire point of writing it down.

1. **Video and method block.** It is every three days, so one skipped block is not a broken habit. It is also the first thing that becomes permanent if you skip it twice, so never skip two in a row.
2. **Reading.**
3. **Morning block**, but only as a named off-day, decided the night before. Never as a default.
4. **The walk**, and this one costs more than it looks. It is the slot that keeps the phone out of your hands.
5. **Writing.** Six sentences. It takes minutes and the whole pipeline is downstream of it.

Never dropped: rosary on waking, Compline, the incipit index. They are two minutes each and they are the frame.

- **A low day is a setting, not a failure.** The call-day version exists so the choice is already made.
